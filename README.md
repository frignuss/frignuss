## Featured project

### [DeskPulse — Windows endpoint diagnostics](https://github.com/frignuss/deskpulse)

A one-click, local Windows diagnostics app for real help-desk workflows.
DeskPulse runs a hidden read-only PowerShell collector, evaluates system, disk,
network, DNS, service, printer, and event data, then presents evidence-based
troubleshooting guidance in a modern Electron/React interface.

- Portable Windows EXE; no installation, command line, account, or cloud dependency
- Device-aware findings, including physical/virtual printer separation
- Typed report contract, hardened Electron IPC boundary, and local report storage
- 13 automated tests plus PSScriptAnalyzer and GitHub Actions checks

[Download the latest Windows build](https://github.com/frignuss/deskpulse/releases/latest)
